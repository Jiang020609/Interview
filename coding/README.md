# Coding

Coding problem solutions and short notes grouped by interview topic.

## Current layout

- `arrays/`: array and interval problems.
- `dp/`: dynamic programming problems, including Hot100 and Codeforces notes.
- `graphs/`: graph traversal, shortest path, DSU, and related problems.
- `trees/`: binary tree and tree traversal problems.
- `strings/`: substring, sliding window, and string-processing problems.
- `math/`: probability, bit manipulation, combinatorics, and numeric reasoning.
- `backtracking/`: DFS, recursion, search, permutations, and combinations.
- `linked-lists/`: linked list implementation and pointer problems.
- `matrices/`: grid and matrix manipulation problems.

## Conventions

Use the original problem ID when possible, such as `lc238` or `CF1195C`. Keep code and analysis next to each other, and add an `analysis.md` when the reasoning is not obvious from the solution.
